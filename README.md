# Number Guessing Game

A simple command-line Number Guessing Game built using Python. The player has to guess a randomly generated number within a limited number of attempts based on the selected difficulty level.

## Features

* Three difficulty levels:

  * Easy (10 attempts)
  * Medium (7 attempts)
  * Hard (5 attempts)
* Random number generation
* Input validation
* Helpful hints for incorrect guesses
* Score calculation
* Best score tracking during the game
* Play Again option
* Simple command-line interface

## Technologies Used

* Python 3

## Gameplay

1. Choose a difficulty level.
2. The computer randomly selects a number between 1 and 100.
3. Enter your guesses.
4. The game provides hints if your guess is too high or too low.
5. Guess the correct number before you run out of attempts.
6. Your score is displayed when you win.
